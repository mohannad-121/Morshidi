# Morshidi World-Class Capability Matrix

## Registry contract

This is the canonical world-class capability registry. IDs are stable and never reused. Status values are limited to `PLANNED`, `PARTIALLY_ENABLED`, `EXTERNAL_DEPENDENCY`, and `FUTURE_SCALE`. Proposal relations mean `DIRECT`, `SUPPORTS`, or `BEYOND`; they do not change proposal compliance status.

Synthetic-demo values are `FULLY_BUILDABLE_LOCALLY`, `DEMO_WITH_SYNTHETIC_DATA`, `REQUIRES_REAL_DATA_FOR_VALIDATION`, or `REQUIRES_INSTITUTIONAL_INTEGRATION`.
