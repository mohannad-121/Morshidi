# Morshidi Technical Handoff Document (One-Page)
# وثيقة التسليم التقني المختصرة لفرق تكنولوجيا المعلومات في الجامعة

> **وثيقة تمهيدية تسلّم لفريق تكنولوجيا المعلومات قبل الاجتماع التقني الأول.**

---

### 1. ما هو مرشدي (Morshidi)؟
مرشدي هو منصة أكاديمية ذكية للإرشاد الأكاديمي، التخطيط الفصلي، واستشراف مسار التخرج، مدعومة بمحرك ذكاء مؤسسي لإدارات الكليات والقبول والتسجيل.
- **المبدأ الحاكم:** الذكاء الاصطناعي يشرح — والقواعد الحتمية الصارمة تقرر.
- **نظام الجامعة (SIS) يبقى المرجع الرسمي المعتمد دائماً.**

---

### 2. ما هي الأنظمة المطلوب ربطها؟
1. **بوابة واجهات برمجة التطبيقات (SIS REST API Gateway):** لقراءة الكتالوج، الشعب، والبيانات الأكاديمية للطلبة.
2. **مزود الهوية الموحد (SSO / IdP):** (اختياري في المرحلة الأولى) للتحقق من هوية الطلبة عبر OIDC أو SAML 2.0.

---

### 3. ما هي البيانات التي يحتاجها مرشدي؟
- **ملف الطالب:** الرقم الجامعي، الاسم، الكلية، التخصص، رقم الخطة الدراسية، الساعات المقطوعة، والمعدل التراكمي.
- **سجل المواد المقطوعة:** رموز المواد، الفصول، والعلامات (ناجح/راسب).
- **التسجيلات الحالية:** الشعب والمواد المسجلة في الفصل الجاري.
- **الخطة الدراسية والكتالوج:** المتطلبات الإجبارية والاختيارية والمتطلبات السابقة والساعات المعتمدة.
- **جدول الشعب المطروحة:** الشعب، المواعيد، والطاقة الاستيعابية.

---

### 4. ما هي البيانات التي لا يطلبها مرشدي نهائياً (Data Minimization)؟
- ❌ **الأرصدة والبيانات المالية** وحالة دفع الرسوم.
- ❌ **السجلات الطبية والصحية.**
- ❌ **السجلات التأديبية والعقوبات.**
- ❌ **الأرقام الوطنية أو أرقام جوازات السفر.**
- ❌ **عناوين السكن وبيانات أولياء الأمور.**

---

### 5. كيف يتم الربط التوثيقي والأمني؟
- **حظر الاتصال المباشر بقواعد البيانات (Zero DB-to-DB):** لا يُطلب إطلاقاً اتصال مباشر بقاعدة بيانات SQL (Oracle, SQL Server, Postgres).
- **التشفير:** تشفير إلزامي لجميع القنوات عبر TLS 1.2+ / HTTPS.
- **قوائم السماح (IP Allowlisting):** خوادم مرشدي ترسل الطلبات من عناوين IP ثابتة يتم تزويدكم بها لإضافتها في الجدار الناري.
- **حماية الأسرار:** لا يتم تخزين مفاتيح الـ API في نصوص صريحة بقواعد البيانات، بل كمتغيرات بيئة مشفرة على مستوى خوادم التشغيل.
- **حماية الويب هوك:** توقيع جميع الإشعارات اللحظية بـ HMAC-SHA256 مع نافذة صلاحية 300 ثانية لمنع هجمات الإعادة.

---

### 6. ما الذي يحتاجه مرشدي في البيئة التجريبية (Sandbox)؟
- رابط Gateway للبيئة التجريبية (Sandbox Base URL).
- بيانات اعتماد حساب API (Client ID & Secret).
- عدد (6-10) حسابات طلابية تجريبية/وهمية تمثل سيناريوهات أكاديمية مختلفة (مستجد، متفوق، متعثر، متوقع تخرجه).

---

### 7. ماذا يحدث خلال المرحلة التجريبية (Pilot Phase)؟
- **نمط القراءة فقط الصارم (READ_ONLY_PILOT):** النظام يعمل بنمط غير معدل نهائياً لحالة نظام الجامعة. لا تسجيل ولا سحب ولا تعديل على بيانات الـ SIS.
- **مطابقة الكيانات الأكاديمية:** مطابقة رموز الكليات والتخصصات والمواد عبر قوالب CSV قياسية.
- **تدقيق النتائج ومطابقة الفروقات:** التأكد التام من تطابق نتائج الأهلية والمعدلات قبل التوصية بأي خطوة لاحقة.

---

### 8. من يشارك في المشروع؟
- **منسق تقني من الجامعة (Technical Lead):** لتوفير وثائق الواجهات واعتمادات الـ Sandbox.
- **منسق أكاديمي / تسجيل (Registrar / Academic Lead):** لمراجعة مطابقة الخطط الدراسية وقواعد المتطلبات السابقة.
- **مسؤول أمن المعلومات (Security Contact):** لتقييم الجدار الناري واعتماد الربط.
- **فريق مرشدي التقني والأكاديمي:** يتولى التجهيز، الفحص، المزامنة، وتوليد تقرير الجاهزية.
