# 04 - Required Data Fields & Data Minimization
# مصفوفة حقول البيانات وسياسة تقليص البيانات وحماية الخصوصية

يرجى مراجعة المواصفة الكاملة في: [Data Fields & Privacy Requirements](../data-fields-required.md).

### 1. مصفوفة الحقول المطلوبة (Data Matrix)
- **الطالب:** الرقم الجامعي (إلزامي)، الاسم الكامل (إلزامي)، الكلية والتخصص (إلزامي)، رقم الخطة (إلزامي)، الساعات المقطوعة والمعدل التراكمي (مشروط).
- **المادة:** رمز المادة (إلزامي)، الاسم العربي (إلزامي)، الساعات المعتمدة (إلزامي)، المتطلبات السابقة (مشروط).
- **العلامة:** رمز المادة (إلزامي)، الفصل (إلزامي)، النتيجة ناجح/راسب (إلزامي)، العلامة المئوية أو الحرفية (مشروط).
- **الشعبة:** رقم الشعبة (إلزامي)، السعة والمقاعد الشاغرة (إلزامي)، الجدول الزمني والقاعة (اختياري).

### 2. البيانات المحظورة والمستثناة تماماً (Strictly Excluded Fields)
انطلاقاً من مبدأ **تقليص البيانات (Data Minimization)**، يتعهد مرشدي بعدم طلب أو تخزين:
- البيانات المالية وحسابات الرسوم والأقساط.
- السجلات الطبية والصحية للطلبة.
- السجلات التأديبية والعقوبات السلوكية.
- الأرقام الوطنية أو وثائق الهوية المدنية.
- عناوين السكن الخاصة وبيانات الاتصال العائلية.

# 05 - Curriculum Mapping Guide
# دليل مطابقة الخطط الدراسية والكتالوج الأكاديمي

يرجى مراجعة قوالب المطابقة المرفقة في مجلد `templates/`:
- `faculty_mapping.csv`: مطابقة رموز الكليات.
- `major_mapping.csv`: مطابقة رموز التخصصات.
- `plan_mapping.csv`: مطابقة أرقام وإصدارات الخطط الدراسية.
- `course_mapping.csv`: مطابقة رموز المواد الأكاديمية.
- `term_mapping.csv`: مطابقة رموز الفصول والتقويم الأكاديمي.

### معايير القبول للمطابقة:
- **100%** لخطط الدفعة التجريبية المستهدفة (Pilot Cohort Plans).
- **لا يقل عن 90%** لمواد التخصص في الدفعة التجريبية.
- **انعدام** أي رموز مجهولة في المواد الإجبارية الأساسية.
