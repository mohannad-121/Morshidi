# 08 - Sandbox Requirements & Synthetic Test Matrix
# متطلبات البيئة التجريبية ومصفوفة الطلبة الوهميين للاختبار

يرجى مراجعة الدليل الكامل في: [Sandbox Testing Guide](../sandbox-testing-guide.md).

### 1. متطلبات البيئة التجريبية (Sandbox)
- بيئة منفصلة مادياً أو منطقياً عن بيئة الإنتاج الخاصة بالجامعة.
- توفر بوابة REST API كاملة تحاكي مخرجات بيئة الإنتاج.
- توفر بيانات وهمية ومواد وشعب دراسية مطابقة للفصل الدراسي القادم.

### 2. مصفوفة الطلبة الوهميين للاختبار (Synthetic Test Personas)
يرجى تحضير الحسابات وفق القالب المرفق `templates/test_students.csv`:
1. **طالب مستجد (Freshman Cold Start):** 0 ساعات مقطوعة، لا سجل سابق، لاختبار توصيات الفصل الأول.
2. **طالب سنة ثانية متفوق (Mid-Degree Good Standing):** 45 ساعة، معدل مرتفع، لاختبار المتطلبات السابقة.
3. **طالب متعثر في متطلب سابق (Failed Prerequisite):** رسوب في مادة متطلب، لاختبار منع تسجيل المادة اللاحقة.
4. **طالب متوقع تخرجه (Near Graduation):** إنجاز 120 ساعة، لاختبار شروط التخرج ومواد المشروع.
5. **طالب معيد لمادة (Repeated Course):** إعادة مادة لرفع المعدل، لاختبار سياسة احتساب العلامة الأحدث.
6. **طالب محول بين تخصصين (Changed Major):** معادلة مواد بين خطتين دراسيتين مختلفتين.

# 09 - Read-Only Pilot Scope
# نطاق التشغيل التجريبي بنمط القراءة فقط

### 1. الميزات المفعلة في نمط القراءة فقط (Enabled)
- التحقق من الهوية والدخول الأكاديمي.
- مزامنة الملف الأكاديمي وكشف العلامات.
- فحص الأهلية والمتطلبات السابقة الصارم.
- المخطط الفصلي الذكي وتوصيات المواد.
- استشراف مسار التخرج والمحاكاة الأكاديمية (What-If).
- المرشد الأكاديمي الذكي المستند للقرارات الرسمية.
- أسئلة الذكاء الطلابي وبنك الأسئلة التشخيصية للمواد.
- لوحة الذكاء المؤسسي ومؤشرات الطلب والاختناقات للأقسام.

### 2. العمليات المحظورة تماماً (Blocked Actions)
- ❌ **حظر تسجيل المواد (Register):** مرشدي لا ينفذ أي عملية تثبيت مقعد أو إضافة شعبة في نظام الجامعة.
- ❌ **حظر سحب المواد (Drop):** لا يمكن سحب أي مساق رسمي من نظام الجامعة عبر مرشدي.
- ❌ **حظر تعديل أي سجل أكاديمي:** لا يمكن تغيير علامة أو خطة أو حالة طالب في نظام الجامعة نهائياً.
- **أي تفعيل لنمط الكتابة (WRITE_ENABLED_PILOT) يتطلب اجتياز بوابة الاعتماد الخاصة المشروطة بـ 12 معياراً.**
