# 00 - Executive Technical Overview
# الملخص التقني التنفيذي لمشروع الربط التجريبي

### 1. الرؤية والهدف
يهدف هذا المشروع لتشغيل بيئة تجريبية آمنة وذكية لمنصة **مرشدي** بالشراكة مع الجامعة لتمكين الطلبة من التخطيط الفصلي الذكي وتزويد إدارات الكليات والتسجيل بمؤشرات استباقية للطلب والاختناقات الأكاديمية، مع الحفاظ الكامل على سيادة وموثوقية نظام معلومات الطلبة (SIS) التابع للجامعة.

### 2. المبادئ الحاكمة للربط
1. **الذكاء يشرح — والقواعد الحتمية تقرر:** لا تتدخل نماذج الذكاء الاصطناعي في إقرار الأهلية أو النجاح أو التخرج؛ المحركات الحتمية هي التي تطبق تعليمات الجامعة بدقة.
2. **نظام الجامعة هو المرجع الرسمي الأول والأخير:** مرشدي لا يحل محل نظام معلومات الطلبة، بل يتكامل معه كطبقة ذكاء وإرشاد متقدمة.
3. **نمط القراءة أولاً (Read-Only First):** تبدأ المرحلة التجريبية بنمط قراءة فقط دون أي تعديل أو كتابة على قاعدة بيانات الجامعة.
4. **العزل التام والخصوصية:** عزل كامل لبيانات الجامعة عبر تقنيات Multi-Tenancy و Row-Level Security، دون جمع أي بيانات مالية أو شخصية غير لازمة.
5. **حظر الاتصال المباشر بقواعد البيانات:** الربط يتم حصرياً عبر واجهات RESTful مشفرة أو تبادل رموز الهوية الموحدة.
