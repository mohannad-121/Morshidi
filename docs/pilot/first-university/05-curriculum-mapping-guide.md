# 05 - Curriculum Mapping Guide
# دليل مطابقة الخطط الدراسية والكتالوج الأكاديمي

يرجى مراجعة قوالب المطابقة المرفقة في مجلد `templates/`:
- `faculty_mapping.csv`: مطابقة رموز الكليات.
- `major_mapping.csv`: مطابقة رموز التخصصات.
- `plan_mapping.csv`: مطابقة أرقام وإصدارات الخطط الدراسية.
- `course_mapping.csv`: مطابقة رموز المواد الأكاديمية.
- `term_mapping.csv`: مطابقة رموز الفصول والتقويم الأكاديمي.

### معايير القبول للمطابقة:
- **100%** لخطط الدفعة التجريبية المستهدفة (Pilot Cohort Plans).
- **لا يقل عن 90%** لمواد التخصص في الدفعة التجريبية.
- **انعدام** أي رموز مجهولة في المواد الإجبارية الأساسية.
