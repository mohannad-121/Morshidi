# 06 - Network & Information Security
# متطلبات الشبكة والأمن السيبراني

يرجى مراجعة المواصفة الكاملة في: [Network & Security Requirements](../network-security-requirements.md).

### النقاط الأساسية:
1. **التشفير:** فرض بروتوكول TLS 1.2+ مع حظر الإصدارات القديمة (SSLv3, TLS 1.0, 1.1).
2. **عناوين الـ IP المسموحة (Allowlist):** تزود مرشدي الجامعة بقائمة عناوين خوادمها الثابتة لإضافتها للجدار الناري.
3. **الدفاع الصارم ضد هجمات SSRF:** خوادم مرشدي تحظر أي توجيه داخلي إلى الشبكات الخاصة (RFC 1918) أو خدمات الـ Metadata (`169.254.169.254`).
4. **حماية المفاتيح والأسرار:** لا يتم تخزين كلمات المرور أو المفاتيح في نصوص صريحة بقواعد البيانات، بل كبصمات مشفرة أو مراجع لمتغيرات بيئة معزولة.

# 07 - Inbound Webhooks & Synchronization
# الإشعارات اللحظية ومزامنة البيانات

يرجى مراجعة المواصفة الكاملة في: [Webhook Contract](../webhook-contract.md) و [Sync & Reconciliation](../sync-reconciliation.md).

### النقاط الأساسية:
1. **توقيع الويب هوك:** توقيع الترويسة بـ HMAC-SHA256 عبر الترويسة `x-morshidi-signature`.
2. **الحماية من هجمات الإعادة:** التحقق من الطابع الزمني في الترويسة `x-morshidi-timestamp` ورفض أي طلب يزيد عمره عن 300 ثانية.
3. **منع التكرار (Idempotency):** فحص المعرف الفريد للحدث `x-morshidi-event-id` لتفادي معالجة نفس التغيير مرتين.
4. **تقرير الفروقات (Reconciliation):** كشف أي تباين بين حالة نظام الجامعة والنسخة المتزامنة في مرشدي دون أي تعديل قسري.
