# 09 - Read-Only Pilot Scope
# نطاق التشغيل التجريبي بنمط القراءة فقط

### 1. الميزات المفعلة في نمط القراءة فقط (Enabled)
- التحقق من الهوية والدخول الأكاديمي.
- مزامنة الملف الأكاديمي وكشف العلامات.
- فحص الأهلية والمتطلبات السابقة الصارم.
- المخطط الفصلي الذكي وتوصيات المواد.
- استشراف مسار التخرج والمحاكاة الأكاديمية (What-If).
- المرشد الأكاديمي الذكي المستند للقرارات الرسمية.
- أسئلة الذكاء الطلابي وبنك الأسئلة التشخيصية للمواد.
- لوحة الذكاء المؤسسي ومؤشرات الطلب والاختناقات للأقسام.

### 2. العمليات المحظورة تماماً (Blocked Actions)
- ❌ **حظر تسجيل المواد (Register):** مرشدي لا ينفذ أي عملية تثبيت مقعد أو إضافة شعبة في نظام الجامعة.
- ❌ **حظر سحب المواد (Drop):** لا يمكن سحب أي مساق رسمي من نظام الجامعة عبر مرشدي.
- ❌ **حظر تعديل أي سجل أكاديمي:** لا يمكن تغيير علامة أو خطة أو حالة طالب في نظام الجامعة نهائياً.
- **أي تفعيل لنمط الكتابة (WRITE_ENABLED_PILOT) يتطلب اجتياز بوابة الاعتماد الخاصة المشروطة بـ 12 معياراً.**
